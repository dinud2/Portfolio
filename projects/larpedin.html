LarpedIn

Swift · Meta Wearables SDK

For anyone who wants to post on LinkedIn consistently and get the most out of their Meta glasses.

View on GitHub

What it is:

LarpedIn was built at LarpHacks 2026 to make "larping" on LinkedIn effortless. It uses Meta glasses to capture ordinary moments and turns them into exaggerated, lesson-filled LinkedIn posts.

How it works:

  1. Stream: The iOS app connects to Ray-Ban Meta glasses through Meta's Wearables SDK and streams their camera and microphone. It keeps the last 30 seconds of HEVC video and audio in a rolling buffer in memory.
  2. Clip: Holding the capture button on the glasses (or tapping Clip in the app) cuts the last 5 to 30 seconds into an mp4 and uploads it to the backend.
  3. Process: The backend is an API running in Docker. It uses ffmpeg to pull 32 frames and a mono audio track from the clip.
  4. Write: An audio model transcribes the audio. A second model gets the frames and transcript, writes a dramatically self-important LinkedIn post about the moment, and picks the best frame to go with it.
  5. Post: The backend uploads the frame through LinkedIn's Images API and publishes the post. A Live Activity on the phone's lock screen tracks each step and ends with a "View post" button.

What I learned:

  • I learned how to work with live video on iOS: decoding HEVC with VideoToolbox, and keeping a rolling buffer so a clip can be cut from the past instead of starting a recording when the button is pressed.
  • I learned how to build a multimodal AI pipeline, splitting transcription and writing across two models and giving the writer both the frames and the transcript as context.
  • I learned that model output needs a fallback. The model sometimes skipped picking a frame, so the backend now uses the middle frame when that happens.
  • I learned how LinkedIn's API works: OAuth tokens, uploading images separately before the post, and the fact that it can only create public posts, with no drafts.

What's next:

  • Add authentication to the clip endpoint so only my app can post.
  • Let users review and edit a post on their phone before it goes live.
  • Ship it as a production build once Meta's button and audio streaming APIs are out of beta.
